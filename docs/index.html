WHY

하루 873건, 사람이 다 열어 볼 수 없습니다

2026년 11월 20일 하루에 올라온 나라장터 용역 공고만 873건이었습니다. 공고마다 면허 제한과 참가 지역을 확인하고, HWP 제안요청서를 내려받아 읽어야 합니다. 이 일을 AI에 맡기려고 API를 연결해 보니 세 곳에서 막혔습니다.

조회 기간 7일

2026-11-10 공지 이후 한 번에 조회할 수 있는 기간이 날짜 기준 7일(양끝 포함)로 줄었습니다. 하루만 넘겨도 07 오류가 납니다.

공개 정보의 빈틈

API의 면허·지역 제한만 보면 공고 대부분이 '참가 가능'으로 보입니다. 그런데 SW 용역 공고문은 대개 직접생산확인증명서를 요구합니다. 시험에서 추천 상위 3건이 모두 이 조건에 걸렸습니다.

숨은 제안요청서

조달청 대행 공고의 실제 제안요청서는 e발주 첨부에만 있습니다. PDF 변환본은 2026 년처럼 띄어쓰기가 깨져 HWP를 직접 읽어야 합니다.

WHAT'S DIFFERENT

찾기에서 끝나지 않습니다

01

말하는 대로 찾습니다

"이번 주", "최근 30일", "5억", "2천5백만원"을 그대로 받습니다. 영문 키워드는 단어 단위로 맞추고('AI'가 'LPAI'에 걸리지 않게), 같은 공고의 여러 차수는 최신 하나로 합치며, 취소공고는 뺍니다. 결과마다 D-day, 사업 유형, 낙찰하한율, 기술:가격 비율이 붙습니다.

02

제안요청서를 끝까지 읽습니다

HWP, HWPX, PDF, DOCX, XLSX, ZIP과 e발주 첨부까지 읽습니다. 제안요청서 → 과업지시서 → 공고문 순으로 고르고, 다른 공고의 파일이 잘못 붙어 있으면 경고합니다.

03

거짓 '참가 가능'을 막습니다

면허 그룹, 참가 지역, 자격등록 마감, 실적·지명 제한 표시에 더해 공고문의 직접생산확인, 중소기업·소기업·대기업 참여 제한까지 원문 문장을 근거로 대조합니다. 조건을 찾지 못했거나 요건인지 불명확하면 '참가 가능'이 아니라 '확인 필요'로 남깁니다.

04

시세를 정직하게 보여 줍니다

낙찰 통계를 경쟁·단독, 그리고 낙찰방법별로 나눕니다. 한 표본에서 수의시담은 99.6%, 소액수의견적은 88.5%로 하나의 중앙값이 의미를 잃었습니다. 투찰 순위, 사정률, 낙찰자 투찰률과 실제 하한율(A값 반영)의 차이, 추첨 예비가격도 봅니다. 845개사가 겨룬 공사에서 낙찰자는 실제 하한보다 0.001%p 위였습니다.

05

반복 업무를 한 장으로 끝냅니다

스킬 /nara가 회사 프로필 인터뷰, 주간 공고 브리핑(briefing.md), 공고 검토 보고서(rfp-brief.md)를 정해진 형식으로 만듭니다. 관심 검색은 물어볼 때마다 지난번 이후 새 공고만 돌려주고, 내 컴퓨터의 예약 작업과 함께 쓰면 매주 아침 브리핑이 됩니다. 판정 결과는 저장해 두고 다시 쓰므로 매주 새 공고만 호출을 씁니다.

INSTALL

준비 2가지, 설치 한 줄

uv파이썬과 의존성을 알아서 맞춥니다. 터미널에서 한 번 설치합니다. 
curl -LsSf https://astral.sh/uv/install.sh | sh
공공데이터포털 인증키입찰공고정보서비스를 활용신청합니다(자동승인). 낙찰 도구까지 쓰려면 낙찰정보서비스도 신청합니다. 키는 발급 후 1~2시간 뒤부터 동작합니다.
Claude Code플러그인으로 설치합니다. 저장소를 직접 받는 방법과 Claude 데스크탑 앱 설정은 README에 있습니다.
1

플러그인 설치

Claude Code 안에서 입력합니다. MCP 서버와 스킬 /nara가 함께 설치됩니다.

/plugin install nara --marketplace airoasting/nara-mcp
2

인증키 입력

설치하면 설정 창이 열립니다. 공공데이터포털 인증키 칸에 키를 넣으면 키체인에 저장됩니다. 나중에 바꾸려면 /plugin configure nara@nara-mcp를 엽니다.

3

첫 질문

Claude Code를 다시 열고 프로필부터 만듭니다.

/nara 우리 회사 프로필부터 만들자
LIMITS

이것은 입찰 자문이 아닙니다

공고문 조건은 문장 패턴으로 찾습니다. 직접생산, 중소기업·소기업, 대기업 참여 제한을 봅니다. 실적·인력 요건과 신용등급은 검토 보고서의 참가 자격 표로 확인합니다.
투찰 참고 하한은 참고용입니다. 응답에 있는 A값 항목을 반영하지만 산식은 공고의 적용 기준마다 다릅니다. 투찰 전 나라장터 화면의 하한을 확인합니다.
읽지 못하는 첨부가 있습니다. 암호 HWP, 배포용 HWP(미리보기만), 스캔 이미지 PDF(OCR 없음).
긴 기간은 약 35일까지입니다. 그보다 오래된 공고는 공고번호로 직접 조회합니다.
